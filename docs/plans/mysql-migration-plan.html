07 · BFF and security contract

Quy tắc không thể thương lượng

Desktop/public client

  • Không MySQL URL/password, client secret, service token hoặc signing key.
  • System browser + Authorization Code + PKCE.
  • Refresh token trong OS Keychain; access token ngắn hạn.
  • Deep link/loopback callback kiểm state, nonce và exact redirect.

BFF/trusted server

  • Verify issuer, signature, audience, expiry và token type.
  • Derive identity/tenant/workspace; deny by default.
  • Validate payload; rate limit theo subject/workspace/IP.
  • Pool MySQL; secrets ở server secret store; audit mutation.
Không dùng local daemon như security boundary. Người dùng kiểm soát máy desktop và có thể gọi loopback/BFF ngoài UI. Mọi authz quan trọng phải được BFF thực thi lại.
08 · Data movement and search

Import order, type policy và FTS

Spy import order

  1. operations
  2. spy_runs
  3. channels
  4. video_snapshots
  5. video_transcripts
  6. transcript_segments
  7. frame_samples
  8. metrics, profiles
  9. competitors

schema_version là SQLite migration metadata, không phải domain row. FTS shadow tables không import.

Verifier

  • Row count + primary-key set.
  • 0 hard FK orphan.
  • JSON semantic equality.
  • UTC/millisecond round-trip.
  • Numeric min/max/sum or checksum.
  • AUTO_INCREMENT > max ID.
  • Artifact reference, byte length và SHA-256.
UUID hiện có          → CHAR(36) CHARACTER SET ascii + case-sensitive collation
SHA-256               → CHAR(64) CHARACTER SET ascii + case-sensitive collation
business identifier   → bounded VARCHAR + explicit case-sensitive collation
Vietnamese content    → utf8mb4
timestamps            → DATETIME(3), UTC, API emits ISO-8601 Z
counters/cursors      → BIGINT [UNSIGNED khi domain không âm]
duration/media time   → DOUBLE
structured payload    → JSON
large prose           → LONGTEXT
FTS hard gate: parser mặc định tách từ theo whitespace; ngram được MySQL mô tả cho CJK. Không chọn ngram cho tiếng Việt chỉ vì có Unicode. Đo precision, recall, phrase behavior, dấu và ordering trên corpus thật.
09 · Infrastructure and recovery

Baseline tự vận hành MySQL

Network

  • 3306 private-only.
  • HTTPS 443 reverse proxy.
  • TLS verify identity.
  • OS/firewall/container patching.

Backup/PITR

  • Daily full, encrypted.
  • Copy off-server.
  • Continuous binary logs.
  • Documented retention.

Observability

  • Disk, CPU, memory, connections.
  • Pool wait/timeout.
  • Slow queries/deadlocks.
  • Backup age and restore status.
Single server = single point of failure. Backup không phải HA. Nếu downtime vượt SLO, cần replica/failover hoặc managed MySQL; đây là ADR-M9, không được ngầm giả định.

11 · Change and recovery

Cutover & rollback

  1. Thông báo maintenance; chặn command/write mới.
  2. Drain/interrupt task có kiểm soát; dừng daemon.
  3. Checkpoint WAL; tạo immutable SQLite backup + checksum.
  4. Xác nhận off-server MySQL backup, binlog archive và restore drill mới nhất.
  5. Chạy forward migrations bằng migration user.
  6. Final import theo FK order; set AUTO_INCREMENT; build search.
  7. Chạy verifier 100% và security smoke trên BFF.
  8. Đổi daemon config sang HTTPS BFF; read-only smoke.
  9. Mở writes; theo dõi error/latency/pool/locks/disk/auth.
  10. Giữ SQLite backup read-only suốt rollback window.

Trước first MySQL write

Dừng BFF, đổi daemon về immutable SQLite snapshot và verify. Đây là rollback sạch.

SAFE

Sau first MySQL write

Không blind-flip về SQLite vì thiếu delta. Forward-fix hoặc reverse-export delta có verifier.

CONTROLLED ONLY
12 · Definition of Done

Tiêu chí hoàn tất

Data & behavior

  • 100% count/PK/FK/JSON verification.
  • Không mất cursor, ID, Unicode, time hoặc precision.
  • Team/Spy/Training/MCP/CLI giữ contract.
  • Golden Vietnamese search đạt threshold.
  • Artifact unavailable được biểu diễn đúng giữa thiết bị.

Security & operations

  • Không DB/secret/signing credential trong desktop.
  • 3306 không public; runtime user không DDL.
  • BFF authz/tenant isolation pass.
  • Restore drill đạt RPO/RTO.
  • Không hidden SQLite fallback hoặc direct DB path.
  • SDD/README/runbooks nhất quán.
Release rule: không đánh dấu hoàn tất nếu baseline, authz isolation, data verifier, FTS acceptance hoặc restore drill còn đỏ.
