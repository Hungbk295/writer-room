Spy Dashboard API

Đi kèm spy-research-pipeline-v3-lean.html · 2026-09-25 · DRAFT

0 · Kết luận

Một bộ 16 endpoint GET read-only dưới /api/spy/dash/* đọc thẳng schema v13, trả JSON phẳng để vẽ biểu đồ không cần biến đổi thêm. Không endpoint nào ghi dữ liệu — việc ghi (duyệt kênh/keyword) vẫn chỉ qua POST /api/spy/loop/decide, giữ nguyên nguyên tắc HITL.

1 · Quy ước chung

Quy ướcGiá trị
AuthNhư các route /api/spy/* hiện có (token daemon)
Tham số bắt buộctopic_id (trừ /topics, /quota, /meta)
Khoảng thời gianfrom, to = YYYY-MM-DD theo quota_day; mặc định 28 ngày gần nhất
Phân tranglimit (mặc định 50, tối đa 500), offset
Sắp xếpsort (whitelist theo endpoint), order=asc|desc
Envelope{ data: [...] | {...}, meta: { topic_id, as_of, total?, limit?, offset?, from?, to? } }
SốSố thô (integer/float), không format locale — bài học sự cố 74.68 → 746830645091782
Thời gianISO-8601 UTC; khoá ngày là quota_day
Giá trị chưa đủ dữ liệunull, không bao giờ 0 (vd views_gained_24h khi mới có 1 snapshot)
Lỗi400 tham số sai · 404 topic/entity không có · { error: string }
Xuất CSVMọi endpoint dạng danh sách nhận format=csv

4 · Triển khai

  • Truy vấn đặt ở packages/spy/src/dash-queries.ts (hàm thuần nhận Database), route ở packages/daemon/src/spy/dash-routes.ts, http.ts chỉ thêm một dòng mount — tránh phình http.ts.
  • Thêm index: video_daily_views(topic_id, day), decisions(topic_id, at DESC), topic_videos(topic_id, published_at DESC).
  • Không materialize bảng mới; mọi chỉ số tính khi đọc. Nếu /hot hoặc /timeseries vượt 300 ms trên dữ liệu thật mới cân nhắc cache.

5 · Tiêu chí chấp nhận

  1. 16 endpoint trả 200 trên DB đã di trú pov-finance; mỗi endpoint có ≥1 test route thật.
  2. /dash/decisions meta.summary.hitl_violations = 0 sau khi chạy daily + weekly + setup.
  3. /dash/hot?date=D trả cùng kết quả khi gọi hôm nay và 7 ngày sau (tính từ snapshot lịch sử).
  4. Không field số nào là chuỗi; không field "chưa đủ dữ liệu" nào trả 0 thay cho null.
  5. Mọi endpoint p95 < 300 ms trên DB thật; format=csv mở được bằng Google Sheets không lệch số.
  6. Không route nào dưới /dash nhận method khác GET.
