2 · Ba flow, bốn điểm dừng

SETUP (1 lần/topic)
  S1 HUMAN  tạo topic: market, language, region + 3–5 seed keyword (+ seed channel tuỳ chọn)
  S2 CODE   search seed kw → gom kênh → cổng ngôn ngữ → quét 30 video/kênh → baseline, outlier
            → topic_channels(status=new)
  ⏸ STOP 1  người duyệt inbox kênh (thumbnail, median, video tốt nhất, bội số) → active | rejected
  S3 CODE   n-gram 2–3 từ title của kênh active, xuất hiện ở ≥3 kênh → topic_keywords(status=pending)
  ⏸ STOP 2  người duyệt keyword → active | rejected            ⇒ setup_status=done

DAILY (tự chạy, giờ cấu hình; KHÔNG gọi search)
  D1 CODE   pre-flight quota; fail → báo Telegram, không ghi dữ liệu
  D2 CODE   mỗi kênh active: 15 video mới nhất (metadata) → upsert topic_videos + 1 snapshot/ngày
  D3 CODE   tính views_gained_24h, outlier_score = views / baseline_median; cập nhật baseline kênh
  D4 CODE   gợi ý (không đổi status): kênh im lặng ≥60 ngày → suggestion='pause_silent'
  D5 CODE   báo cáo ngày: video mới, top 10 tăng view, top outlier, gợi ý → daily_reports + Telegram
  ⏸ STOP 3  người đọc báo cáo; nếu muốn thì xử lý gợi ý (không chặn tick sau)

WEEKLY OUTLIER (1 lần/tuần, giờ cấu hình)
  W1 CODE   search ≤12 keyword active (xoay vòng theo last_checked_at), region/lang, 28 ngày gần nhất
            → ghi sức khoẻ keyword (n_results, n_followed, median view)
  W2 CODE   outlier TRONG follow: video 7 ngày qua có outlier_score ≥ 3
  W3 CODE   outlier NGOÀI follow: kênh chưa có trong list, có video hit; quét nhanh ≤10 kênh
            → bội số ≥3 và không xổ số → topic_channels(status=new, discovered_via=weekly_outlier)
  W4 CODE   n-gram chung của ≥2 video outlier → topic_keywords(status=pending, origin=outlier_title)
  W5 CODE   báo cáo tuần → daily_reports(mode=weekly) + Telegram
  ⏸ STOP 4  người duyệt inbox: kênh mới, keyword mới, gợi ý pause

Luật bất biến: code chỉ được ghi new, pending, rejected (duy nhất cho lang_mismatch) và suggestion. Chuyển sang active / paused / rejected vì lý do khác chỉ qua endpoint duyệt, actor='human'.

4.5 Bảng mới

-- Mỗi video mà topic đang theo dõi (1 dòng / topic / video). Giá trị "latest_*" là bản sao để dashboard đọc nhanh.
CREATE TABLE topic_videos (
  topic_id TEXT NOT NULL,
  video_id TEXT NOT NULL,
  channel_id TEXT NOT NULL,
  title TEXT NOT NULL,
  published_at TEXT,
  duration_sec REAL,
  thumbnail_url TEXT,
  source TEXT NOT NULL,            -- setup | daily_scan | weekly_search
  found_by_keyword TEXT,           -- term_key khi source=weekly_search
  first_seen_at TEXT NOT NULL,
  latest_views INTEGER, latest_likes INTEGER, latest_comments INTEGER, latest_at TEXT,
  views_gained_24h INTEGER,        -- NULL khi chưa có 2 snapshot (L6)
  outlier_score REAL,              -- latest_views / baseline_median; NULL khi baseline chưa tin cậy
  PRIMARY KEY (topic_id, video_id)
);
CREATE INDEX idx_topic_videos_channel ON topic_videos(topic_id, channel_id, published_at DESC);
CREATE INDEX idx_topic_videos_outlier ON topic_videos(topic_id, outlier_score DESC);

-- Snapshot view, append-only, tối đa 1 dòng / video / ngày.
CREATE TABLE video_daily_views (
  topic_id TEXT NOT NULL,
  video_id TEXT NOT NULL,
  day TEXT NOT NULL,               -- YYYY-MM-DD (quota_day)
  views INTEGER NOT NULL, likes INTEGER, comments INTEGER,
  captured_at TEXT NOT NULL,
  PRIMARY KEY (topic_id, video_id, day)
);

-- Nhật ký mọi đổi trạng thái kênh/keyword — bằng chứng cho tôn chỉ 1.
CREATE TABLE decisions (
  id TEXT PRIMARY KEY,
  topic_id TEXT NOT NULL,
  at TEXT NOT NULL,
  actor TEXT NOT NULL CHECK(actor IN ('human','loop')),
  entity_type TEXT NOT NULL CHECK(entity_type IN ('channel','keyword')),
  entity_id TEXT NOT NULL,
  from_status TEXT, to_status TEXT NOT NULL,
  reason TEXT NOT NULL,
  tick_id TEXT
);
CREATE INDEX idx_decisions_entity ON decisions(topic_id, entity_type, entity_id, at DESC);
